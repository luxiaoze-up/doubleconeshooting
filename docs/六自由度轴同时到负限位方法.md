# 六自由度设备：轴同时到负限位操作指南

## 概述

本文档说明如何让六自由度设备的六个轴同时移动到负限位（EL-）位置，这是一个常见的初始化、校准或安全操作。

---

## 限位概念

### 限位类型

六自由度设备每个轴有两个硬件限位开关：

| 限位类型 | 符号 | 返回值 | 说明 |
|---------|------|--------|------|
| 正限位 | EL+ | 1 | 轴正向运动极限位置 |
| 负限位 | EL- | -1 | 轴负向运动极限位置 |
| 无限位 | - | 0 | 轴在中间位置 |

### 读取限位状态

```python
import tango

device = tango.DeviceProxy("sys/six_dof/1")

# 读取单个轴的限位状态
axis = 0  # 轴 0-5
el_state = device.command_inout("readEL", axis)

if el_state == 1:
    print(f"轴 {axis} 在正限位 (EL+)")
elif el_state == -1:
    print(f"轴 {axis} 在负限位 (EL-)")
else:
    print(f"轴 {axis} 未触发限位")
```

## 方法对比

### 方法一：使用 sixMoveZero 命令（推荐）

**适用场景**：系统初始化、回零操作

```python
import tango

device = tango.DeviceProxy("sys/six_dof/1")

# 所有轴同时移动到零位（负限位）
device.command_inout("sixMoveZero")
```

**工作原理**：
- 自动向运动控制器发送所有 6 个轴的 `moveZero` 命令
- 运动控制器会让每个轴以负方向运动
- 触发负限位开关后自动停止
- 将该位置定义为零位

**代码实现**：[src/device_services/six_dof_device.cpp#L1157-1203](../src/device_services/six_dof_device.cpp#L1157-1203)

```cpp
void SixDofDevice::sixMoveZero() {
    check_state("sixMoveZero");
    
    // 检查是否有限位故障锁存
    if (limit_fault_latched_.load()) {
        throw_exception("限位故障已锁存，请先执行 reset");
    }
    
    // 获取运动控制器代理
    auto motion = get_motion_controller_proxy();
    
    // 循环发送所有轴的 moveZero 命令
    for (int axis = 0; axis < NUM_AXES; ++axis) {
        Tango::DeviceData data_in;
        data_in << static_cast<Tango::DevShort>(axis);
        motion->command_inout("moveZero", data_in);
    }
    
    set_state(Tango::MOVING);
}
```

**优点**：
- ✅ 简单方便，一条命令完成
- ✅ 自动处理所有轴
- ✅ 内置安全检查
- ✅ 设置零点位置

**缺点**：
- ⚠️ 运动速度和参数由系统预设

### 方法二：使用 movePoseAbsolute 到极限负姿态

**适用场景**：需要精确控制运动过程

```python
import tango

device = tango.DeviceProxy("sys/six_dof/1")

# 定义极限负姿态（根据实际限位调整数值）
# [X, Y, Z, ThetaX, ThetaY, ThetaZ]
extreme_negative_pose = [-17.0, -17.0, -17.0, -4.0, -4.0, -4.0]

# 移动到极限负姿态
device.command_inout("movePoseAbsolute", extreme_negative_pose)

# 等待运动完成
import time
while device.state() == tango.DevState.MOVING:
    time.sleep(0.1)
    
print("已到达负限位")
```

**注意事项**：
- 需要知道系统的姿态限位值
- 默认限位：位置 ±17mm，旋转 ±4°
- 实际限位需根据机械结构确定

**工作原理**：
1. 通过逆运动学计算目标腿长
2. 发送各轴的绝对运动命令
3. 轴会运动到目标位置或触发限位停止

### 方法三：单轴逐个运动到负限位

**适用场景**：需要单独控制每个轴的运动顺序

```python
import tango
import time

device = tango.DeviceProxy("sys/six_dof/1")

# 定义大负值（超出行程范围，确保触发限位）
large_negative = -500.0  # mm

for axis in range(6):
    print(f"正在移动轴 {axis} 到负限位...")
    
    # [axis, position]
    params = [float(axis), large_negative]
    device.command_inout("singleMoveAbsolute", params)
    
    # 等待该轴运动完成或触发限位
    timeout = 30  # 30秒超时
    start_time = time.time()
    
    while time.time() - start_time < timeout:
        # 读取限位状态
        el_state = device.command_inout("readEL", axis)
        if el_state == -1:  # 触发负限位
            print(f"✓ 轴 {axis} 已到达负限位")
            break
        time.sleep(0.1)
    else:
        print(f"⚠ 轴 {axis} 运动超时")
    
    # 短暂延迟后处理下一个轴
    time.sleep(0.5)

print("所有轴已到达负限位")
```

**优点**：
- ✅ 可以观察每个轴的运动过程
- ✅ 可以自定义运动顺序
- ✅ 便于调试

**缺点**：
- ⚠️ 运动时间较长（串行而非并行）
- ⚠️ 代码复杂

### 方法四：直接调用运动控制器（底层方法）

**适用场景**：绕过六自由度设备，直接控制电机

```python
import tango

# 获取运动控制器（六自由度使用控制器 3）
motion_ctrl = tango.DeviceProxy("sys/motion/3")

# 同时发送所有轴的 moveZero 命令
for axis in range(6):  # 六自由度占用 AXIS 0-5
    motion_ctrl.command_inout("moveZero", axis)
    print(f"轴 {axis} moveZero 命令已发送")

print("等待运动完成...")
```

**注意事项**：
- ⚠️ 绕过了六自由度设备的安全检查
- ⚠️ 不会更新六自由度设备的状态
- ⚠️ 可能导致刹车、限位等状态不同步
- ❌ **不推荐使用**，除非用于底层调试

## 完整操作流程

### 1. 准备工作

```python
import tango
import time

# 连接设备
device = tango.DeviceProxy("sys/six_dof/1")

# 1.1 检查设备状态
state = device.state()
print(f"当前状态: {state}")

if state == tango.DevState.FAULT:
    print("设备处于故障状态，执行复位...")
    device.command_inout("reset")
    time.sleep(2)

# 1.2 检查是否需要释放刹车
# （六自由度设备在运动前会自动释放刹车，通常无需手动操作）

# 1.3 检查驱动器是否上电
# 可以通过 queryPowerStatus 命令查询
try:
    power_status = device.command_inout("queryPowerStatus")
    print(f"电源状态: {power_status}")
except:
    print("无法查询电源状态，继续...")

print("准备工作完成")
```

### 2. 执行回零操作

```python
# 方法 A：使用 sixMoveZero（推荐）
print("开始回零操作...")
device.command_inout("sixMoveZero")

# 监控运动状态
while True:
    state = device.state()
    print(f"\r状态: {state}", end='', flush=True)
    
    if state == tango.DevState.ON:
        print("\n✓ 回零完成")
        break
    elif state == tango.DevState.FAULT:
        print("\n✗ 发生故障")
        break
    
    time.sleep(0.2)
```

## 安全注意事项

### ⚠️ 运动前检查

1. **确认无障碍物**：确保平台运动范围内无障碍物或人员
2. **检查刹车状态**：确认刹车已释放（自动处理）
3. **确认驱动器上电**：通过 `enableDriverPower` 命令上电
4. **检查限位开关**：确认所有限位开关正常工作
5. **急停准备**：确保急停按钮可触及

### ⚠️ 限位故障处理

如果触发限位导致故障锁存：

```python
# 检查是否有限位故障
alarm_state = device.read_attribute("alarmState").value
print(f"告警状态: {alarm_state}")

if alarm_state:
    # 执行复位清除故障
    device.command_inout("reset")
    time.sleep(1)
    
    # 反向移动离开限位
    for axis in range(6):
        el_state = device.command_inout("readEL", axis)
        if el_state == -1:  # 在负限位
            # 正向移动 5mm
            params = [float(axis), 5.0]
            device.command_inout("singleMoveRelative", params)
            time.sleep(1)
```

### ⚠️ 紧急停止

```python
# 方法 1: 停止六自由度设备
device.command_inout("Stop")

# 方法 2: 直接停止运动控制器（更底层）
motion_ctrl = tango.DeviceProxy("sys/motion/3")
for axis in range(6):
    motion_ctrl.command_inout("stopAxis", axis)
```

## 测试脚本

创建完整的测试脚本：[scripts/test_six_move_to_negative_limit.py](../scripts/test_six_move_to_negative_limit.py)

```python
#!/usr/bin/env python3
"""
六自由度设备：移动到负限位测试脚本
"""

import sys
import time
import tango

def test_move_to_negative_limit(device_name="sys/six_dof/1", method="sixMoveZero"):
    """
    测试移动到负限位
    
    Args:
        device_name: 设备名称
        method: 使用的方法 ('sixMoveZero', 'pose', 'single')
    """
    print(f"\n{'='*70}")
    print(f"六自由度设备 - 移动到负限位测试")
    print(f"设备: {device_name}")
    print(f"方法: {method}")
    print(f"{'='*70}\n")
    
    try:
        # 连接设备
        device = tango.DeviceProxy(device_name)
        device.ping()
        print("✓ 设备连接成功\n")
        
        # 检查状态
        state = device.state()
        print(f"当前状态: {state}")
        
        if state == tango.DevState.FAULT:
            print("设备处于故障状态，执行复位...")
            device.command_inout("reset")
            time.sleep(2)
        
        # 用户确认
        print("\n⚠️  即将移动所有轴到负限位")
        print("请确认:")
        print("  1. 平台周围无障碍物")
        print("  2. 人员已退出安全区域")
        print("  3. 急停按钮可触及")
        
        response = input("\n是否继续? (y/n): ")
        if response.lower() != 'y':
            print("操作取消")
            return
        
        # 执行移动
        print(f"\n开始执行 ({method})...")
        start_time = time.time()
        
        if method == "sixMoveZero":
            device.command_inout("sixMoveZero")
        elif method == "pose":
            extreme_pose = [-17.0, -17.0, -17.0, -4.0, -4.0, -4.0]
            device.command_inout("movePoseAbsolute", extreme_pose)
        elif method == "single":
            for axis in range(6):
                print(f"  移动轴 {axis}...")
                params = [float(axis), -500.0]
                device.command_inout("singleMoveAbsolute", params)
                time.sleep(0.5)
        
        # 监控运动
        print("监控运动状态...")
        while True:
            state = device.state()
            print(f"\r状态: {state:15s}", end='', flush=True)
            
            if state == tango.DevState.ON:
                print("\n✓ 运动完成")
                break
            elif state == tango.DevState.FAULT:
                print("\n✗ 发生故障")
                break
            
            time.sleep(0.2)
        
        elapsed = time.time() - start_time
        print(f"运动时间: {elapsed:.1f} 秒")
        
        # 读取结果
        print("\n各轴状态:")
        print(f"{'轴':<4} {'编码器/mm':>12} {'限位状态':>10}")
        print(f"{'-'*30}")
        
        encoder_values = device.command_inout("readEncoder")
        for axis in range(6):
            enc_val = encoder_values[axis]
            el_state = device.command_inout("readEL", axis)
            status = {-1: "EL-", 0: "中间", 1: "EL+"}[el_state]
            print(f"{axis:<4} {enc_val:>12.4f} {status:>10}")
        
        # 检查所有轴是否都在负限位
        all_at_neg_limit = all(
            device.command_inout("readEL", i) == -1 
            for i in range(6)
        )
        
        if all_at_neg_limit:
            print("\n✓ 所有轴已到达负限位")
        else:
            print("\n⚠ 部分轴未到达负限位")
        
    except tango.DevFailed as e:
        print(f"\n✗ Tango 错误:")
        for err in e.args:
            print(f"  {err.reason}: {err.desc}")
        sys.exit(1)
    except KeyboardInterrupt:
        print("\n\n⚠ 用户中断")
        device.command_inout("Stop")
    except Exception as e:
        print(f"\n✗ 错误: {e}")
        sys.exit(1)

if __name__ == "__main__":
    import argparse
    
    parser = argparse.ArgumentParser(description='六自由度设备移动到负限位测试')
    parser.add_argument('device', nargs='?', default='sys/six_dof/1',
                       help='设备名称 (默认: sys/six_dof/1)')
    parser.add_argument('--method', choices=['sixMoveZero', 'pose', 'single'],
                       default='sixMoveZero',
                       help='使用的方法 (默认: sixMoveZero)')
    
    args = parser.parse_args()
    test_move_to_negative_limit(args.device, args.method)
```

## 故障排查

### 问题 1：运动控制器未连接

**现象：**
```
API_ProxyError: Motion controller not connected
```

**解决方法：**
```python
# 检查运动控制器状态
motion = tango.DeviceProxy("sys/motion/3")
print(motion.state())

# 如果是 OFF，执行连接
motion.command_inout("connect")
```

### 问题 2：限位故障锁存

**现象：**
```
LIMIT_FAULT_LATCHED: Limit fault is latched; please run reset before moving.
```

**解决方法：**
```python
# 执行复位清除故障
device.command_inout("reset")
time.sleep(1)

# 反向移动离开限位
for axis in range(6):
    params = [float(axis), 5.0]  # 正向移动 5mm
    device.command_inout("singleMoveRelative", params)
```

### 问题 3：刹车未释放

**现象：**
电机无法运动或运动时有异响

**解决方法：**
```python
# 手动释放刹车（通常自动处理）
device.command_inout("releaseBrake")
time.sleep(0.5)
```

### 问题 4：驱动器未上电

**现象：**
```
运动命令无响应
```

**解决方法：**
```python
# 检查电源状态
status = device.command_inout("queryPowerStatus")
print(status)

# 如果未上电，执行上电
device.command_inout("enableDriverPower")
time.sleep(1)
```
