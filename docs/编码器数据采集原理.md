# 编码器数据采集系统原理说明

## 概述

本文档详细说明 `sys/encoder/1` Tango 设备如何同时从两个编码器采集器读取数据，并提供统一的访问接口。

**硬件配置：**
- 编码器采集器 1：192.168.1.199:5000（物理通道 1-10）
- 编码器采集器 2：192.168.1.198:5000（物理通道 1-8）
- 协议：TCP Socket 通信
- 数据格式：7 字节帧协议

### 通道映射

采集器通过 `channel_offset` 自动映射到全局通道：

| 采集器 | IP地址 | 物理通道 | 全局通道 | 用途 |
|--------|--------|----------|----------|------|
| 采集器1 | 192.168.1.199 | CH1-CH10 | 1-10 | 六自由度(1-6)、大行程(7)、反射光部分(8-10) |
| 采集器2 | 192.168.1.198 | CH1,2,3,4,6,7,8,9 | 11-18 | 反射光部分(11-13)、辅助支撑(14-18) ※跳过CH5 |

**详细通道分配：**

```
全局通道 1-6:   六自由度轴 1-6
全局通道 7:     大行程
全局通道 8:     反射光设备1-X
全局通道 9:     反射光设备1-Y  
全局通道 10:    反射光设备2-X
全局通道 11:    反射光设备2-Y
全局通道 12:    反射光设备1-Z
全局通道 13:    反射光设备2-Z
全局通道 14:    辅助支撑设备1
全局通道 15-18: 辅助支撑设备2-5 (注: 192.168.1.198物理CH5未连接编码器，被跳过)
```

```cpp
EncoderAcquisitionManager::EncoderAcquisitionManager(
    const std::vector<std::string>& ips, 
    const std::vector<int>& ports,
    int channels_per_collector) {
    
    std::vector<EncoderCollectorConfig> configs;
    int channel_offset = 1;  // 从通道 1 开始
    
    for (size_t i = 0; i < ips.size(); ++i) {
        int port = (i < ports.size()) ? ports[i] : 5000;
        configs.push_back({
            ips[i], 
            port, 
            channel_offset,           // 采集器1: offset=1, 采集器2: offset=11
            channels_per_collector    // 10
        });
        channel_offset += channels_per_collector;
    }
    
    // 创建客户端
    for (const auto& cfg : configs) {
        clients_.emplace_back(new EncoderAcquisitionClient(
            cfg.ip, 
            cfg.port, 
            cfg.channel_offset, 
            cfg.channel_count,
            shared_readings_,        // 共享数据缓存
            shared_mutex_            // 互斥锁
        ));
    }
}
```

## 数据采集机制

### 1. TCP 连接建立

每个 `EncoderAcquisitionClient` 在独立线程中运行：

```cpp
void EncoderAcquisitionClient::run() {
    while (running_) {
        // 1. 尝试连接
        if (!connected_ && !connect_socket()) {
            sleep(1);
            continue;
        }
        
        // 2. 接收数据
        uint8_t buffer[1024];
        int n = recv(socket_fd_, buffer, sizeof(buffer), 0);
        
        // 3. 追加到缓冲区
        buffer_.insert(buffer_.end(), buffer, buffer + n);
        
        // 4. 解析帧
        parse_buffer();
    }
}
```

### 2. 数据帧协议

**帧格式（7 字节）：**

```
┌──────┬─────────┬──────────────────────┬──────┐
│ 0x7E │ channel │   raw_value (4B)     │ 0x7F │
│      │  (1B)   │   (big-endian)       │      │
└──────┴─────────┴──────────────────────┴──────┘
  帧头    通道号      原始编码器值          帧尾
```

**示例：**
```
0x7E 03 12 34 56 78 0x7F
→ 物理通道 3, 原始值 0x12345678
```

### 3. 数据解析

位置：[src/common/encoder_acquisition.cpp#L208-236](../src/common/encoder_acquisition.cpp#L208-236)

```cpp
void EncoderAcquisitionClient::handle_frame(const uint8_t *frame) {
    // 提取通道号（物理通道，0-based）
    uint8_t channel = frame[1];
    
    // 提取 32 位原始值（大端序）
    uint32_t raw = (frame[2] << 24) | (frame[3] << 16) | 
                   (frame[4] << 8)  | frame[5];
    
    // 解析绝对编码器值：
    // 高 15 位 = 圈数（turns）
    // 低 17 位 = 单圈内位置（position）
    uint16_t turns = (raw >> 17) & 0x7FFF;
    uint32_t position = raw & 0x1FFFF;
    
    // 合成最终值：整数部分 + 小数部分
    double combined_value = turns + (position / 1000000.0);
    
    // 计算全局通道号
    int global_channel = channel_offset_ + channel;
    // 采集器1: global = 1 + (0~9) = 1~10
    // 采集器2: global = 11 + (0~7) = 11~18
    
    // 写入共享缓存（带互斥锁保护）
    {
        std::lock_guard<std::mutex> lock(readings_mutex_);
        readings_[global_channel].raw_value = raw;
        readings_[global_channel].turns = turns;
        readings_[global_channel].position = position;
        readings_[global_channel].combined_value = combined_value;
        readings_[global_channel].timestamp = now;
        readings_[global_channel].valid = true;
    }
}
```

### 4. 编码器分辨率转换

编码器设备在读取时会应用分辨率转换：

```cpp
double EncoderDevice::readEncoder(Tango::DevShort channel) {
    // 从管理器读取原始值
    EncoderReading reading;
    encoder_manager_->get_reading(channel, reading);
    
    // 应用分辨率（单位：mm/count）
    double resolution = encoder_resolution_arr_[channel];  // 默认 0.00274658
    double position_mm = reading.combined_value * resolution;
    
    return position_mm;
}
```

## 并发与线程安全

### 1. 多线程模型

```
Main Thread (Tango)
    ↓ 调用 readEncoder(7)
    ↓
Manager::get_reading(7)
    ↓ 加锁读取
    ↓ ───────────────────────────────
    ↓                                 │
    ↓                          Shared Cache
    ↓                          readings_[1-18]
    ↓                                 │
    ↓ ─────────────────────────────── 
    ↑ 加锁写入              ↑ 加锁写入
    │                       │
Client Thread 1       Client Thread 2
(192.168.1.199)       (192.168.1.198)
    │                       │
接收 TCP 数据         接收 TCP 数据
解析帧                解析帧
写入 readings_[1-10]  写入 readings_[11-18]
```

### 2. 互斥锁保护

```cpp
// 共享数据结构
std::vector<EncoderReading> readings_;  // 大小 20
std::mutex readings_mutex_;

// 写入（Client线程）
void handle_frame(...) {
    std::lock_guard<std::mutex> lock(readings_mutex_);
    readings_[global_channel] = new_value;
}

// 读取（Tango命令线程）
bool get_reading(int channel, EncoderReading& out) {
    std::lock_guard<std::mutex> lock(readings_mutex_);
    out = readings_[channel];
    return out.valid;
}
```

### 3. 原子操作

```cpp
std::atomic<bool> running_;     // 线程运行标志
std::atomic<bool> connected_;   // 连接状态
```

## 容错与重连

### 1. 自动重连机制

```cpp
void EncoderAcquisitionClient::run() {
    while (running_) {
        if (!connected_) {
            // 连接失败，等待后重试
            if (!connect_socket()) {
                std::this_thread::sleep_for(
                    std::chrono::seconds(1)
                );
                continue;
            }
        }
        
        // 正常接收数据...
        // 如果发生错误，connected_ 会被清除，
        // 下次循环自动重连
    }
}
```

### 2. 独立容错

- 每个采集器客户端独立运行
- 一个采集器断开不影响另一个
- 断开的采集器自动尝试重连
- 数据缓存保留最后有效值

### 3. 状态监控

```cpp
// 检查是否有任何连接
bool has_any_connection() const {
    for (auto& client : clients_) {
        if (client->is_connected()) {
            return true;
        }
    }
    return false;
}

// 获取状态摘要
std::string status_summary() const {
    std::stringstream ss;
    ss << "Collectors: " << clients_.size();
    int connected = 0;
    for (auto& c : clients_) {
        if (c->is_connected()) connected++;
    }
    ss << ", Connected: " << connected;
    return ss.str();
}
```

## 性能特点

### 1. 数据更新率

- **采集器发送频率**：约 1000 Hz（每毫秒一帧）
- **TCP 接收**：持续非阻塞接收
- **缓存更新**：实时更新共享缓存
- **Tango 读取**：按需读取，无延迟

### 2. 延迟分析

```
采集器发送 ──→ TCP传输 ──→ 客户端接收 ──→ 解析 ──→ 写缓存 ──→ Tango读取
  <1ms         1-2ms        <1ms        <1ms      <1ms       <1ms
                                                            
总延迟：< 5ms (通常 2-3ms)
```

### 3. 资源占用

- **线程数**：2 个后台线程（每个采集器一个）
- **内存**：约 100 KB（主要是缓冲区）
- **CPU**：< 1%（空闲时），2-3%（高速运动时）
- **网络**：约 7 KB/s 每个采集器（1000 fps × 7 字节）

## 总结

**核心优势：**

1. **透明访问**：上层只需调用 `readEncoder(channel)`，无需关心物理采集器分布
2. **高可靠性**：自动重连、独立容错、数据缓存
3. **高性能**：并发采集、无阻塞读取、低延迟
4. **易扩展**：配置驱动、支持任意数量采集器
5. **线程安全**：互斥锁保护、原子操作

**设计模式：**
- 生产者-消费者模式（后台线程生产，Tango命令消费）
- 代理模式（Manager 代理多个 Client）
- 单例模式（共享数据缓存）
