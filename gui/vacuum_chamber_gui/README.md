# 真空腔体系统控制 GUI (Vacuum Chamber Control GUI)

打靶控制系统 - 双锥项目激光打靶实验综合控制界面

## 项目概述

本 GUI 是基于 PyQt5 和 Tango 控制系统开发的综合性图形界面，用于双锥项目激光打靶实验系统的完整控制。系统涵盖靶定位、成像观测、辅助支撑和真空环境控制的全部功能。

## 核心功能

### 🎯 1. 靶定位 (Target Positioning)

靶的精密定位系统，包含粗定位和精密调整两个层级。

**功能特性：**
- **大行程运动控制**
  - 三轴粗定位（X/Y/Z）
  - 行程范围：X/Y ±500mm, Z ±200mm
  - 精度：0.01mm
  
- **六自由度精密调整**
  - 位置调整：X/Y/Z 三个平移自由度
  - 姿态调整：RX/RY/RZ 三个旋转自由度
  - 精度：0.001mm / 0.001°
  
- **电机状态监控**
  - 7个电机实时状态（6个六自由度 + 1个大行程）
  - 显示内容：位置、编码器值、运动状态、限位开关
  
- **独立电机控制**
  - 每个六自由度电机可单独控制
  - 支持相对运动、停止、复位操作

**对应设备：**
- 大行程设备：`sys/large_stroke/1`
- 六自由度设备：`sys/six_dof/1`
- 运动控制器：`sys/motion/3` (192.168.1.13)
- 编码器通道：0-6

---

### 📷 2. 反射光成像 (Reflection Imaging)

双平台成像系统，支持 4 个 CCD 相机的图像采集和三坐标控制。

**功能特性：**
- **双平台三坐标控制**
  - 上平台（设备1）：X/Y/Z 三轴独立控制
  - 下平台（设备2）：X/Y/Z 三轴独立控制
  - 运动范围：X/Y ±500mm, Z ±250mm
  - 精度：0.01mm
  
- **CCD 相机系统**
  - 上平台：1倍物镜相机 + 10倍物镜相机
  - 下平台：1倍物镜相机 + 10倍物镜相机
  - 型号：海康威视 MV-CU020-19GC
  - 分辨率：1920×1080
  - 曝光时间可调：0.1-10.0ms
  
- **环形光源控制**
  - 上下平台环形光独立开关
  
- **电机状态监控**
  - 6个电机状态显示（上下平台各3轴）
  - 只读模式，无直接控制按钮

**对应设备：**
- 反射光成像设备：`sys/reflection/1`
- 运动控制器：`sys/motion/2` (192.168.1.12)
- 编码器通道：7-12
- 轴映射：
  - 上平台：X(AXIS-0), Y(AXIS-2), Z(AXIS-4)
  - 下平台：X(AXIS-1), Y(AXIS-3), Z(AXIS-5)

---

### 🔧 3. 辅助支撑 (Auxiliary Support)

5组独立辅助支撑设备的控制和力值监控。

**功能特性：**
- **5组独立设备**
  - 设备1-4：已安装（M14-M17）
  - 设备5：未安装（M18，预留）
  
- **标准操作**
  - 夹持/释放：设定目标位置并执行夹持或释放操作
  - 上移/下移：快速移动控制
  - 停止：紧急停止运动
  - 复位：电机复位操作
  
- **力传感器监控**
  - 实时显示当前力值
  - 目标力值设定
  - 力值单位：N（牛顿）
  
- **电机状态显示**
  - 5个辅助支撑电机状态
  - 只读模式，通过功能按钮控制

**对应设备：**
- 辅助支撑设备：`sys/auxiliary/1` ~ `sys/auxiliary/5`
- 运动控制器：`sys/motion/1` (192.168.1.11)
- 编码器通道：13-17
- 力传感器分布：
  - 设备1-2：控制器3 AIN0
  - 设备3-4：控制器2 AIN0
  - 设备5：控制器1 AIN0

### 🌀 4. 真空抽气控制 (Vacuum Control)

完整的真空系统控制，包含泵阀控制、监控和数据记录。

**功能特性：**
- **多标签页设计**
  - **配置控制**：泵阀手动控制面板
  - **数字孪生**：系统流程图可视化
  - **报警记录**：告警历史查看
  - **历史记录**：操作日志记录
  - **趋势曲线**：压力等参数的实时曲线
  
- **泵阀控制**
  - 前级泵（机械泵）控制
  - 分子泵控制
  - 各类阀门：机械泵阀、分子泵阀、进气阀、插板阀等
  - 真空度实时监控
  
- **安全联锁**
  - 自动联锁保护逻辑
  - 防误操作设计
  - 状态实时监控

**对应设备：**
- 真空系统：`sys/vacuum/1` (简化版) / `sys/vacuum/2` (完整版)
- 联锁服务：`sys/interlock/1`

## 系统架构

### 技术栈
- **前端框架**：PyQt5
- **控制系统**：Tango (CORBA-based)
- **通信协议**：Tango DeviceProxy
- **图形渲染**：PyQtGraph (趋势曲线)
- **多线程**：QThread (后台通信)

### 架构特点

1. **多线程架构**
   - 每个功能模块都有独立的后台通信线程（Worker）
   - UI 线程与通信线程分离，避免界面阻塞
   - 使用 QMutex 保护共享数据

2. **状态缓存机制**
   - 后台线程定期轮询设备状态
   - 状态数据缓存在 Worker 中
   - UI 定时拉取缓存数据，避免高频信号导致卡顿

3. **模拟模式支持**
   - `SimulationModeManager` 全局管理
   - 支持无硬件的仿真运行
   - 便于开发和测试

4. **统一样式主题**
   - 深色主题设计（`VACUUM_CHAMBER_THEME`）
   - 一致的视觉风格
   - 响应式布局

5. **模块化设计**
   - 页面级模块分离（`pages/`）
   - 组件级复用（`widgets/`）
   - 配置与代码分离（`config.py`）

## 安装和使用

### 环境要求

```bash
Python >= 3.7
PyQt5 >= 5.12
PyTango >= 9.3.0
pyqtgraph >= 0.11.0  (可选，用于趋势曲线)
```

### 安装依赖

```bash
# 进入 GUI 目录
cd gui/vacuum_chamber_gui

# 安装 Python 依赖
pip install -r requirements.txt
```

### 启动应用

**方法1：直接运行**
```bash
python main.py
```

**方法2：使用启动脚本**
```bash
# 从项目根目录
./start_gui.sh
```

### 配置说明

所有配置项都在 `config.py` 中定义：

1. **设备名称配置** (`DEVICES`)
   - 必须与 Tango 数据库注册一致
   - 格式：`"device_key": "sys/device/instance"`

2. **导航结构配置** (`NAVIGATION`)
   - 定义侧边栏菜单项
   - 包含页面 ID、名称、图标、描述

3. **UI设置** (`UI_SETTINGS`)
   - 窗口大小、刷新间隔等
   - 状态面板宽度可按页面定制

4. **功能参数配置**
   - `TARGET_POSITIONING_CONFIG`：靶定位参数
   - `REFLECTION_IMAGING_CONFIG`：反射光成像参数
   - `AUXILIARY_SUPPORT_CONFIG`：辅助支撑参数
   - `VACUUM_CONTROL_CONFIG`：真空控制参数

## 开发指南

### 添加新页面

1. 在 `pages/` 目录创建新的页面模块
2. 继承 `QWidget` 并实现页面布局
3. 在 `config.py` 的 `NAVIGATION` 中添加导航项
4. 在 `main_window.py` 的 `_create_pages()` 中实例化

### 添加新组件

1. 在 `widgets/` 目录创建组件类
2. 继承合适的 Qt 控件基类
3. 应用统一的样式主题
4. 在 `widgets/__init__.py` 中导出

### 样式定制

在 `styles.py` 中修改 `VACUUM_CHAMBER_THEME` 字典：
- 使用 Qt StyleSheet 语法
- 支持选择器、伪类、属性选择器
- 建议使用 `objectName` 进行精确控制

## 故障排查

### 常见问题

**1. 设备连接失败**
- 检查 Tango 数据库是否运行
- 确认设备服务器是否启动
- 验证设备名称配置是否正确

**2. GUI 卡顿**
- 检查刷新间隔设置（`UI_SETTINGS.refresh_interval_ms`）
- 确认后台线程是否正常运行
- 查看终端日志是否有异常

**3. 电机状态不更新**
- 确认编码器设备连接正常
- 检查编码器通道配置
- 验证运动控制器通信

**4. 相机图像无法显示**
- 检查相机供电（OUT1）
- 确认相机驱动是否安装
- 验证图像保存路径权限

### 调试模式

启用模拟模式进行调试：
```python
# 在代码中设置
self.sim_mode_manager.set_simulation_mode("device_name", True)
```

或在界面中切换模拟模式开关。
